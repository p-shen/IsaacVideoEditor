# Captions and text attachments implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task. The handoff explicitly authorizes completion of the approved rank-8 design; continue inline without another design round.

**Goal:** Complete editable SRT captions and explicit title/caption attachments while preserving the delivered title workflow and advanced editor.

**Architecture:** Store captions separately as styled frame-timed text, reuse the canonical Qt/MLT renderer and committed-state history/recovery/export snapshots, and share stable clip-ID/source-frame attachment rules with visuals. Add a dedicated captions inspector and native timeline lane; extend title attachment controls without duplicating existing text features.

**Tech stack:** Existing C++17, Qt 6 Quick/QML/Gui, MLT, CMake, QtTest; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-25-qt-quick-interaction-design.md`, sections 7–8; handoff in `docs/remaining-interaction-roadmap.md`.

## Global constraints

- Keep versions 1–6 loadable. New caption/attachment data uses version 7; retain original text content, timing and rendering.
- All timing uses 60 fps and exclusive ends. Minimum caption duration is one frame. Preserve imported overlaps and out-of-sequence cues.
- Captions default to Project time. Sequence reorder/duration edits retain them and mark timing for review.
- Explicit attach/detach applies to titles and captions. Reuse stable Clip.id/source-frame split/trim/delete rules; retain desired caption duration and visibly show project-end clamping.
- Burn captions is independent of SRT output and never removes manual titles.
- Preserve compact icons, the inspector trash control, window-title save status, empty-viewer import, and absence of Starts at/playback-position slider.
- Automatic transcription remains deferred. Preserve newer unrelated work at delivery using hashes and reconcile conflicts.

## Review focus

- SRT rounding must round-trip all frame boundaries, handle UTF-8/BOM/multiline and reject malformed files atomically.
- Host edits and deletion must preserve intended text or remove it only through the explicit shared removal choice, including Undo.
- Editing/cancellation and selection changes must not leak draft captions into recovery/export or apply draft text to a different row.
- Burn-off exports still contain titles; SRT output retains all captions and overlaps regardless of burn choice.
- Proxy/output resolution changes and fallback fonts must retain wrapping/position/timing, including non-Latin text.
