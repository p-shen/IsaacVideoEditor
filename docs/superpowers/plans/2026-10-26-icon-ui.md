## Global Constraints
- Keep Qt Quick desktop workspace, theme and user text sizing.
- No media editing/encoding changes and no new dependencies.
- Preserve keyboard shortcuts, focus rings, accessible names and drag alternatives.
- SVG icons use one visual family and current semantic foreground colors.
- No Git repository is present: back up sources, keep a progress ledger and compare files directly.

## Review Focus
- Icon controls remain named, focusable and operable with a keyboard in both palettes.
- Checkable Snap/Bold and color swatch retain clear state and accessibility.
- All actions remain reachable at 760x560 and 24pt text.
- Inspector changes preserve numeric bindings, escaped edits and focus selection behavior.
- Filmstrip/waveform failures remain distinct from loading and silent audio.
